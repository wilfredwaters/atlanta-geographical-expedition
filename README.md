# Atlanta Geographical Expedition

The goal of this group is to:

1. Normalize the use of spatial SQL.
2. Use AI for good.
3. Do geospatial for good.

To achieve these goals, we founded Atlanta Geographical Expedition. [An app is in development](https://wilfredwaters.github.io/atlanta-geographical-expedition/), it starts with Dekalb. It uses [CDC's Social Vulnerability Index](https://www.atsdr.cdc.gov/place-health/php/svi/index.html). Each pop up uses that data to show top 5 drivers of social vulnerability, then top 3 structural drivers of the same. The bottom of each pop up has a link to Grok [(example)](https://grok.com/share/c2hhcmQtNA_e395f01b-e74f-4303-b6c4-53adaa6f2095). This uses AI to plan a campaign to address the structural drivers, for the selected census tract. As such, we are using spatial analysis to direct the use of AI for good. It augments our effort to reduce social vulnerability in a targeted way.

[William Bunge was a radical geographer](https://indiemaps.com/blog/2010/03/wild-bill-bunge/) and urbanist who thrived on saying no to academic tradition. In doing so, his work was a precursor to the modern concept of [Participatory GIS](https://en.wikipedia.org/wiki/Participatory_GIS). He was the first in 1968 to run an initiative like this, [Detroit Geographical Expedition](https://digitalcommons.usm.maine.edu/detroitgeographicalexpedition/3/). It was lead by community representative Gwendolyn Warren and mapped issues important to locals. For example, [hotspots in Detroit where children frequently died on sidewalks when hit by cars](https://digital.library.cornell.edu/catalog/ss:19343514).

If we are to form a useful geospatial group in Atlanta, then:

1. We can use his original society-focused expedition as inspiration.
2. We can power our efforts with efficient tooling like spatial SQL.
3. We can be confident our time is well spent by using AI for good and indeed doing good through our geospatial acts.

Data: CDC/ATSDR Social Vulnerability Index 2022 (census tracts). See SUMMARY.md.
